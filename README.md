# Ai-Powered-Stock-Market-Simulator-with-News-Driven-and-Text-Generation
An educational AI-based stock market simulation web application that combines historical stock data, basic machine learning, financial news, and AI-generated insights to help users understand stock market behavior.
This project is designed for students, beginners, and academic demonstrations, not for real trading.
The system fetches real-time and historical stock data from Yahoo Finance and displays it using interactive candlestick charts.
It also integrates financial news APIs and uses basic AI/ML models to simulate price trends and generate simple market insights in natural language.
